    Automatic evidence from city buses — our edge node, real drives

    A laptop-class edge box on a bus runs one object detector (YOLO11 + our pothole model) across four cameras, blurs number plates on the device, and sends only events — not video. Real runs: the Bhubaneswar 4-camera drive, KIIT → Esplanade (19 Sep 2026), where the node was built and tested; and a Varanasi single-camera drive with phone-GNSS geotags (29 Aug 2026). Gemini 2nd opinion re-reads each crop, confirms or rejects the defect and writes the work-order line — so officials act on verified evidence.
